# 📊 Telco Customer Churn Analysis

## 📌 Overview
Analyzed 7044 Telco customers to find out why customers leave (Churn) and built a Machine Learning model to predict it.

**Dataset Source:** Kaggle - Telco Customer Churn

## 📂 Files
- `Telco-Churn.csv` - Dataset with 7044 customers
- `analysis.py` - Python analysis + Model code

## 🛠️ Tools Used
- Python
- Pandas, Matplotlib, Seaborn
- Scikit-learn (Logistic Regression)

## 📈 What I Found
- Overall Churn Rate: **26.5%** (1 in 4 customers leave)
- Customers with **Month-to-month contract** churn the most
- Customers with **Fiber Optic Internet** have higher churn than DSL
- **Model Accuracy: 79%**
